# Veranda Breathing Home

## Project Overview
This project is a modern, minimalist e-commerce frontend for Veranda Breathing Home, focusing on home decor that "breathes".

## Technologies Used
- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Getting Started

### Prerequisites
- Node.js & npm installed

### Installation
1. Clone the repository
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run dev
   ```

## Key Components
- **Navbar**: Main navigation with logo, search, and cart access.
- **Hero**: Highlighted collections and banners.
- **New Arrivals**: Product grid for latest items.
- **Philosophy**: Brand values and story.
- **Journal/Blog**: Content sections for home decor tips.
